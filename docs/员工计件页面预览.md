# 员工计件与部门进度页面预览

入口：工厂管理 → 员工计件（`/workshop/piecework`）、部门进度（`/workshop/progress`）。

当前是可操作的前端原型，使用虚构员工和示例订单；录入保存在当前浏览器的独立预览存储中，不调用正式订单、报价或工资接口。需要长期使用的数据，应等正式数据库功能完成后录入。

## 员工与计件

- 首页按“选员工 → 照纸单录计件 → 看工资合计”显示操作顺序；个人录入默认只显示款号、数量、单价。
- 指令单号、颜色、码数、工序等收在每笔的“补充信息”中，展开可修改；折叠不会清除原有数据。
- 每位员工有姓名、工号、所属部门、默认计件工序、常规月保底。
- 按工资所属月份进入员工明细；例如 10 月工资显示 11 月发放。
- 可手工填写型体、指令单号、颜色、码数、工序、数量、单价。选已有示例订单时带出对应款式；未关联的记录仍可先录工资。
- 每行单价支持四位小数，行金额四舍五入到分，合计按分累加。
- 支持新增、删除明细行、“先保存”和“算工资”；空款号、空单价、非正整数数量等不能计算工资。“算工资”保存核对后的明细并显示计件、保底和较高的工资试算金额。
- 在单价栏按回车新增下一笔。窄窗口以卡片表单显示，宽窗口以表格显示。
- 工资仅作试算，取计件合计与人工填写的本月保底中较高值。“有请假，要调整保底”展开后可修改用于比较的金额。请假按天折算、扣款比较顺序、其他补扣款和发薪月结尚未实现，需确认业务规则。
- 常规保底修改用于尚未保存的新月份，已保存月份使用各自核定的金额。

## 部门进度

- 按订单款式跨月累计，截至所选月份统计，不只计算当月计件。
- 示例完工口径：面部收尾交接、前段完工、贴底完工、包装完工。普通车缝、画线等计件不重复计入部门完工双数；正式口径需用户确认。
- 仅统计关联到订单、对应完工工序且已核对的明细。修改款号、订单、工序或数量后需重新核对。
- “待上前段”使用面部完工减前段累计已接收；“待贴底”使用前段完工减贴底累计已接收。接收数量在订单详情中单独登记。
- 交接数超过上段已登记完工数、完工数超过本段接收数或订单数量时，显示数量待核对。
- 示例按总双数演示，尚未实现实际采购、尺码配套、物料到货和外发管理；事项说明仅供展示和手工编辑。月底集中录入的数据不能代表月中实时进度。

## 验证

在 `web` 目录运行 `npm run build`。预览可通过 `npm run dev -- --host 127.0.0.1` 启动。

浏览器检查覆盖：数量调整后行金额与合计同步变化、保存刷新后保留、空白行阻止核对、手工指令单号可保存、待贴底筛选、9 月与 10 月累计进度切换、交接数量调整后待上前段双数同步变化。检查后恢复示例数量。
